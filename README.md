# 工会战报刀 BOT

基于 NoneBot2 + Python 的工会战报刀机器人，适用于单BOSS顺序推进类工会战。

## 功能列表

- ✅ 报刀 / 撤刀
- ✅ 补偿刀（尾刀后额外获得）
- ✅ 每人每天3刀限制
- ✅ 出刀进度统计与查询
- ✅ BOSS血量追踪（击杀后自动进阶）
- ✅ 预约BOSS（排队）
- ✅ 每日出刀情况图表汇总
- ✅ 自动催刀提醒（可配置时间）
- ✅ 成员注册，一人多账号绑定（刀数合并计算，@时同时@所有账号）
- ✅ 作业（攻略图）上传与查询

## 项目结构

```
guild_war_bot/
├── README.md
├── requirements.txt
├── .env                    # NoneBot2 配置
├── bot.py                  # 入口文件
└── src/
    └── plugins/
        └── guild_war/
            ├── __init__.py
            ├── config.py       # 配置（BOSS血量、刀数等）
            ├── database.py     # SQLite 数据库操作
            ├── models.py       # 数据模型
            ├── handlers.py     # 报刀相关指令
            ├── members.py      # 注册/绑定指令
            ├── homework.py     # 作业指令
            ├── scheduler.py    # 定时任务（催刀）
            └── chart.py        # 图表生成
```

## 安装与运行

```bash
pip install -r requirements.txt
cp .env.example .env   # 按需修改
python bot.py
```

本项目只负责消息逻辑，需要另外运行 QQ 协议端（推荐 NapCat）登录机器人 QQ 号，
并在协议端中添加反向 WebSocket：`ws://127.0.0.1:8080/onebot/v11/ws`。

## 指令列表

| 指令 | 说明 |
|------|------|
| `注册 [游戏名]` | 注册成员（报刀/预约等功能需先注册） |
| `绑定 @小号` | 把小号绑定到自己，刀数合并计算 |
| `绑定 @大号 @小号` | 管理员代为绑定 |
| `解绑 [@账号]` | 解绑账号（不@则解绑自己） |
| `改名 <名字>` | 修改成员名 |
| `我的信息` / `成员列表` | 查看注册信息 |
| `注销 @成员` | 删除成员（管理员） |
| `上传作业 <标题> [图片]` | 上传作业图，可附图、回复图片或随后发送（管理员） |
| `查作业 [编号/关键词]` | 查看作业列表或指定作业 |
| `删除作业 <编号>` | 删除作业（管理员） |
| `报刀 <伤害>` | 记录一刀伤害 |
| `尾刀 <伤害>` | 记录击杀BOSS的最后一刀（获得补偿刀） |
| `补偿刀 <伤害>` | 使用补偿刀 |
| `撤刀` | 撤销最近一次报刀 |
| `预约` | 预约当前BOSS |
| `取消预约` | 取消预约 |
| `出刀进度` | 查看今日全员出刀情况 |
| `BOSS状态` | 查看当前BOSS血量和周目 |
| `今日汇总` | 生成图表并发送 |
| `催刀` | 手动催促未出完刀的成员（超级用户） |
| `开启工会战` | 开始新一天的工会战（超级用户） |
| `结束工会战` | 结束今日工会战（超级用户） |

> 新增指令中的"管理员"指超级用户、群主或群管理员。
